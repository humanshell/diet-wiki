Apolipoprotein B (ApoB) is a primary marker for atherogenic lipoproteins. The [[2026-acc-aha-dyslipidemia-guidelines]] recommends using ApoB for a more accurate assessment of residual atherogenic risk than LDL-C alone.

The guidelines position ApoB as a key marker for residual atherogenic risk, often used alongside [[statin-therapy]] evaluation.
